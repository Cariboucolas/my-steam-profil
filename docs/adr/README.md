# Architecture decisions

Every decision that shaped this codebase, oldest first, with what it settled and what it amends.

Each ADR states its decision and holds its own reasoning; chronology is a property of the set
rather than of any one of them, so it lives here and the ADRs keep their current shape. A later
decision never rewrites an earlier one — it amends it, and both say so.

| #                                                                 | Date       | Decision                                                             | What it settled                                                                                                                                                                                                                                           |
| ----------------------------------------------------------------- | ---------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [0001](0001-backend-proxies-steam.md)                             | 2026-08-18 | The backend proxies Steam                                            | The app never talks to Steam and never holds the API key. Every Steam shape stops at our boundary.                                                                                                                                                        |
| [0002](0002-result-for-expected-failures.md)                      | 2026-08-18 | `Result` for expected failures                                       | A failure the caller must act on is a value, not an exception. Exceptions are for what nobody planned for.                                                                                                                                                |
| [0003](0003-api-runs-on-cloudflare-workers.md)                    | 2026-08-24 | The API runs on Cloudflare Workers                                   | Where the API lives, and that platform knowledge stays in `worker.ts` rather than spreading into routes.                                                                                                                                                  |
| [0004](0004-the-app-refuses-a-game-outside-the-library.md)        | 2026-08-25 | The app refuses a game outside the library                           | Ownership is checked by the caller that already knows, not by a route that would have to ask Steam again.                                                                                                                                                 |
| [0005](0005-the-library-tally-is-cached-the-game-view-is-not.md)  | 2026-08-25 | The library tally is cached, the game view is not                    | One Steam call per tally, cached five minutes; the game view stays live, because that is where a fresh unlock is checked.                                                                                                                                 |
| [0006](0006-the-tally-carries-its-unlock-dates.md)                | 2026-09-02 | The tally carries its unlock dates                                   | The completion route answers `{ completion, unlockedAt }`, on the download ADR-0005 was already making. **Amends 0005.**                                                                                                                                  |
| [0007](0007-the-tone-scale-reads-a-rolling-year.md)               | 2026-09-04 | The tone scale reads a rolling year, the header reads calendar years | The calendar's five tone bands are quartiles of the player's active days over the 365 days ending today, not of the year drawn.                                                                                                                           |
| [0008](0008-rarity-is-cached-long-and-shared.md)                  | 2026-09-08 | Rarity is cached long and shared                                     | A game's published rarity is kept a day under an address carrying no SteamId. Contradicts 0005 in appearance only: nothing player-specific sits under a shared key. **Extended 2026-09-09**: how a game names its achievements falls under the same rule. |
| [0009](0009-the-tally-names-its-unlocks.md)                       | 2026-09-08 | The tally names its unlocks                                          | The completion route answers `{ completion, unlocks }`, each unlock named and dated or undated. A rarity is published per achievement, so a date alone cannot be crossed with it. **Amends 0006.**                                                        |
| [0010](0010-the-app-chooses-its-language.md)                      | 2026-09-10 | The app chooses its language, the device does not                    | Wording, dates and number separators come from the language the app displays, never from the device's locale. A string's width is a layout input, so the app picks its characters.                                                                        |
| [0011](0011-a-figure-shortens-only-when-it-must.md)               | 2026-09-10 | A figure shortens only when it must                                  | The library headline is written in the most informative form that fits the room the screen leaves it, measured rather than thresholded. Binds `UnlockHeadline` alone for now.                                                                             |
| [0012](0012-a-promise-to-hold-text-caps-how-far-it-grows.md)      | 2026-09-10 | A promise to hold text caps how far it grows                         | A box that must hold its text caps the system text size, by a multiplier derived from its own constraint. The headline and its caption stop at 1.13; the calendar's month column opts out. **Amends 0011.**                                               |
| [0013](0013-an-exact-figure-is-paid-for-in-its-own-typography.md) | 2026-09-14 | An exact figure is paid for in its own typography                    | A figure promised exact buys room from its own typography before asking the layout for a pixel. The calendar's month column holds four digits at no cost to the day cells; the cascade 0011 offers is declined, with its reason. **Cites 0011.**          |
| [0014](0014-the-legible-floor-is-where-reading-stops-costing.md)  | 2026-09-14 | The legible floor is where reading stops costing                     | A day cell may be 6 px painted and its gutter 0.5. Measured by forced comparison on a phone, replacing the nine #29 left behind — which was the narrowest layout it happened to sample, drawn in tones the app does not paint.                            |
| [0015](0015-a-figure-crosses-the-wire-its-rendering-does-not.md) | 2026-09-17 | A figure crosses the wire, its rendering does not | Contracts carry figures, identifiers and ISO dates; the screen that draws a number decides what it looks like. `playtimeLabel` was the one exception and it did not hold: its only client already formatted the same figure two other ways. **Cites 0010, 0011, 0013.** |
| [0016](0016-the-app-states-its-revision.md) | 2026-09-21 | The app states its revision, it does not detect that it is behind | The running app names the commit it was built from and never asks whether a newer one exists. Recognising a stale tab is the reader's act, on information the app put in front of them. Decided ahead of #106. |
| [0017](0017-a-report-carries-the-request-not-the-reader.md) | 2026-09-21 | A report carries the request, not the reader | An error report transmits what identifies the request — SteamID included, since it is published rather than confided — and nothing added to identify the reader. Reopened if Steam's official sign-in lands. **Cites 0001, 0016.** |
| [0018](0018-an-alert-crosses-a-bridge-that-cannot-alert-about-itself.md) | 2026-09-22 | An alert crosses a bridge we own, and the bridge cannot alert about itself | Sentry's alerts reach a dedicated Discord through `apps/alerts`, subscribed to `issue.created`, because both the Discord integration and the alert rule action need a paid plan and the free webhook speaks a language Discord refuses. Nothing watches that Worker, and the limit is stated rather than hidden. **Cites 0001, 0003, 0016, 0017.** |
| [0019](0019-a-monitor-stands-outside-what-it-watches.md) | 2026-09-22 | A monitor stands outside what it watches, and remembers in the tracker | A scheduled GitHub Actions probe checks `apps/api` and `apps/alerts`, keeps its state in an `incident` issue per target, and alerts a `health` Discord channel. Off-platform on purpose: a monitor hosted on what it watches goes quiet with it. **Pays the limit stated in 0018. Cites 0003, 0017, 0018.** |
| [0020](0020-a-build-declares-what-its-profile-promises.md) | 2026-09-26 | A build declares what its profile promises | An APK built from `main` states its commit, read on the builder by `metro.config.js`, and claims to be live through the `preview` EAS environment. The builder knows the commit, never the branch. **Amends 0016.** |
| [0021](0021-a-story-shows-a-state-the-device-settles-how-it-looks.md) | 2026-09-27 | A story shows a state, the device settles how it looks | Storybook runs on the web, because its readers need a URL. A story is trusted for the state it reaches, never for its pixels; a rendering question is settled on a device. Decided in #75. **Cites 0011–0014.** |
| [0022](0022-only-a-page-loads-what-it-shows.md) | 2026-09-27 | Only a page loads what it shows | Components follow the five atomic levels, and only a page under `src/components/pages/` calls the `ApiClient`; routes keep what the router owns, and `ApiClientProvider` lets a story serve fixtures. Decided in #75. **Cites 0005.** |
| [0023](0023-the-locale-is-a-setting-and-a-view-model-receives-its-translation-function.md) | 2026-09-29 | The locale is a setting, and a view-model receives its translation function | The locale is `en` or `fr`, persisted beside the SteamID, never read from the device. `i18next` holds the catalogs; a view-model takes a translation function bound to a locale as an argument and reads no global. A parity test guards the catalogs. Decided in #155. **Amends 0010. Cites 0011, 0012, 0022.** |
| [0024](0024-one-tool-lints-and-formats-and-the-gate-runs-it.md) | 2026-10-02 | One tool lints and formats, and the gate runs it | Biome checks lint rules and formatting across the workspace, and `verify` runs it first. The React hook rules are errors; a rule switched off carries its reason in `biome.jsonc`. Decided in #172. |
| [0025](0025-the-cache-lives-above-the-routes-and-a-page-still-loads.md) | 2026-10-05 | The cache lives above the routes, and a page still loads | One `QueryClient` above the routes keeps what the app loaded; pages still decide what to ask. Keys carry the SteamId except rarity and names, a tally can be ten minutes old, one queue of six serves every call, one retry on `UNAVAILABLE`, and the fan-out kept its waves because one render per tally was measured too slow. Decided in #162. **Amends 0022. Cites 0002, 0005, 0008.** |
| [0026](0026-the-project-is-an-application-not-a-domain.md) | 2026-11-12 | The project is an application, not a domain | On a three-level scale — showcase, application, domain — the code is an application: the five atomic levels in front, routes → `SteamGateway` → Steam behind, a framework-free `packages/domain` with no use cases. Records what is, moves nothing, and names what would move it to level 3. **Cites 0002, 0022.** |
| [0027](0027-nothing-leaves-main-unless-ci-passed-on-that-commit.md) | 2026-11-12 | Nothing leaves main unless CI passed on that commit | Every workflow a push to `main` starts calls `ci.yml` first and every one of its jobs waits on that call, since #202 and #203. `pnpm check:workflows`, in `verify`, refuses a workflow that does not. Decided after `deb7697` deployed with CI red on 2026-10-06. |
| [0028](0028-a-risk-tier-is-computed-not-declared.md) | 2026-11-13 | A risk tier is computed, not declared | CI computes each pull request's tier from its paths with the base branch's classifier, whose table and `risk-tiers.ts` a test keeps identical, and writes it in the job summary; it blocks nothing while the owner merges everything. Only paths are read, so a devDependency bump, through its lockfile, is tier 2. |
| [0029](0029-a-pull-request-is-classified-by-main-not-by-itself.md) | 2026-11-17 | A pull request is classified by main, not by itself | `risk-tier.yml`, started by `pull_request_target`, computes the tier and who merges from the files GitHub lists, with `main`'s classifier, and never checks out or runs the pull request's code; `pnpm check:workflows` refuses a workflow on that trigger that would. Forks and Dependabot are never merged automatically. **Amends 0028.** |
| [0030](0030-tier-0-merges-itself-once-verify-passes.md) | 2026-11-17 | Tier 0 merges itself once verify passes | `merge-tier-0.yml`, started by `workflow_run` when CI completes, merges a tier 0 pull request of this repository through the API, pinned to the commit `verify` passed on; never a fork, Dependabot, a draft or another base. The token's merge starts no workflow, so nothing deploys: tier 0 feeds nothing built. **Amends 0028, 0029.** |
| [0031](0031-dependency-updates-come-weekly-grouped-and-read-by-the-owner.md) | 2026-11-17 | Dependency updates come weekly, grouped, and are read by the owner | Dependabot opens version updates every Monday for pnpm and the actions, minor and patch grouped by kind, a seven-day cooldown, majors alone. Every one is tier 2 and merged by the owner; CI is its only automatic judge, since a Dependabot pull request runs without the repository's secrets. **Cites 0028, 0029.** |
| [0032](0032-what-a-guardrail-cites-is-a-guardrail.md) | 2026-11-17 | What a guardrail cites is a guardrail | From `AGENTS.md`, a test follows the links and named Markdown files of every tier 2 document to a fixed point; every document reached is tier 2 and every link leads somewhere. `docs/images/README.md` and `tools/steam-spike/FINDINGS.md` become tier 2. **Amends 0030.** |
| [0033](0033-the-ai-reviewer-reads-a-pull-request-as-data-from-main.md) | 2026-11-17 | The AI reviewer reads a pull request as data, from main | `ai-review.yml`, started by `pull_request_target`, runs Claude Code on the owner's subscription token with `main`'s instructions (`.github/ai-review.md`): it reads the pull request through the API as data, may only read and comment inline, skips forks, Dependabot and drafts, and blocks nothing. `pnpm check:workflows` refuses an unpinned third-party action in a workflow holding `main`'s rights. **Cites 0028–0031.** |
| [0034](0034-a-template-may-pass-on-the-scroll-it-lays-out.md) | 2026-11-18 | A template may pass on the scroll it lays out | A template may take, beside named `ReactNode` props, an ordered list of `{ key, node }` and the scroll and layout handlers of the container it draws, typed by itself and importing nothing from `view-models/`; what a position means stays the page's. Decided in #186 for `StatsTemplate`. **Amends 0022.** |
| [0035](0035-a-preview-is-built-by-the-pull-request-and-deployed-by-main.md) | 2026-11-23 | A preview is built by the pull request and deployed by main | `preview.yml`, on `pull_request`, builds the app and the gallery without a secret and hands them over as an artifact; `preview-deploy.yml`, started by `workflow_run` as `main` has it, reads the pull request through the API, refuses anything Pages would run, deploys with the Cloudflare token and posts the links. Dependabot pull requests get a preview. **Amends 0031; cites 0027, 0029, 0033.** |
